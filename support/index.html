Support

A little clarity goes a long way.

Practical answers for the current RenoQuote workflow.

Where is my project data stored?

Projects, customers and templates are stored locally with SwiftData. Preferences and export usage are local settings; logos are files in Application Support. There is no app account or app-managed cloud sync in Build 22.

Can I use metric and imperial measurements?

Yes. The measurement calculators support both systems. Check actual dimensions, openings, waste and material coverage before purchasing.

Can I enter decimal values with a comma?

Yes. Numeric editors accept both 30.5 and 30,5, preserve temporary editing text and validate before saving.

How do I change language?

Use iOS Settings → Apps → RenoQuote → Language. The app includes English, Turkish, Spanish, German and French. Select quotation language separately in Project Estimate → PDF Export.

What does the Free export limit count?

Every successfully generated Free Customer Quotation counts, including regenerating the same project. Sharing an existing file does not. The allowance is three per UTC calendar month on this device.

What happens when Pro ends?

Existing saved data stays available. Future project/template creation and premium exports follow the Free policy; the app does not delete data because entitlement ends.

How do I restore or manage Pro?

Open Settings → RenoQuote Pro for Restore Purchases and Manage Subscription. Build 22 production sales are disabled; current purchase testing is local StoreKit only.

How do I back up my work?

A complete backup needs the SwiftData store, app preferences and Application Support logo files together. A PDF is an exported document, not a full project backup. Build 22 has no app-managed cross-device synchronization.

Are quantities guaranteed?

No accuracy guarantee is offered. Verify site measurements, manufacturer coverage and layout. Tile quantities are estimates, especially for complex layouts.
