Informations locales de l’app

Build 22 stocke localement mesures, postes, tarifs, notes, clients, modèles et identité d’entreprise avec SwiftData. Préférences, langue/format du devis, référence du logo et compteur d’exports sont locaux. Aucun compte développeur, serveur, outil d’analyse ou API d’IA tierce n’est implémenté.

Logos, PDF et partage

Le PhotosPicker natif sélectionne votre image ; une version normalisée est stockée dans Application Support. Les PDF temporaires locaux peuvent contenir informations d’entreprise, clients et projets. Vous choisissez la destination du partage natif. Elle a ses propres pratiques ; aucun contrôle sur les copies partagées n’est promis.

Services et achats Apple

StoreKit charge les produits et utilise les transactions vérifiées d’Apple pour l’accès. Apple gère ses propres services de compte/paiement ; RenoQuote ne propose pas de formulaire de carte. Achats en production désactivés. Le code ne définit pas toutes les collectes/conservations Apple ; consultez ses avis. Le compteur d’usage est distinct des droits d’achat.

Site et hébergement

Aucun outil d’analyse, publicité, pixel, police externe ou formulaire. JavaScript conserve uniquement une préférence facultative d’apparence dans localStorage, effaçable via les données du navigateur. La langue figure dans l’URL. Selon GitHub, Pages enregistre les IP des visiteurs pour la sécurité. L’hébergement est distinct du code du site ; consultez la déclaration GitHub.

GitHub Pages · GitHub · Apple

Votre contrôle et points en attente

Projets, clients et modèles peuvent être modifiés/supprimés ; le logo retiré. Supprimer un client conserve les informations enregistrées dans les projets. PDF partagés et sauvegardes sont distincts. Désinstallation, restauration et sauvegardes système peuvent affecter les données locales. La conservation par GitHub, Apple ou une future assistance n’est pas déterminée par le code. Exploitant, contact, juridiction, bases légales/droits, conservation et traitement des demandes doivent être validés avant une politique définitive.
